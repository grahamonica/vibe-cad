# Vibe CAD 1.2.0

Reload refreshes the saved design through the current MCP connection, preserving the embedded editor instead of navigating its frame away from the host. Renderer retirement and confirmed host closure are tracked separately, so stale lease records cannot permanently prevent a new editor from opening. Live editors and unsaved drafts retain their existing protections.

The viewport rejects lightweight inspection summaries as renderable geometry, including after a superseded transfer. A transient build-status request failure no longer disables status polling permanently.

Large CAD and drawing exports are delivered through bounded MCP file resources. The export response retains file identity and size rather than another full base64 copy. Download chunks are checked against the same saved file version; no external server or daemon is introduced.

Validation: focused lifecycle, view-contract and multi-chunk file-transfer checks; production build and release package verification. Native embedded-host verification must be completed after activating the installed version.
